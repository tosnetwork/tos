# NftAuthorTrial

Generated by `tol new --pattern nft` for the Slice 3 Stage 8
external-author trial surrogate. This project is intentionally close to
raw generator output so release reviewers can inspect what a new author
starts from.

## Build

```sh
tol --check-only src/main.tol
```

## Test

```sh
tol-tester tests nft-positive
```

## Files

- `src/main.tol` - scaffold contract using `@stdlib/nft`
- `tests/nft-positive.tol` - smoke test for the generated pattern
- `replay/nft-replay.json` - deterministic replay trace stub
- `deploy/deploy.json` - deployment skeleton
- `artifacts/*.json` - opcode, method-id, error-code, and replay observability maps

See `doc/slice-3-external-author-trial.md` for the under-one-hour
checklist and current human-trial status.
