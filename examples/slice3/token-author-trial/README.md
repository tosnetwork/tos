# TokenAuthorTrial

Generated by `tol new --pattern token` for the Slice 3 Stage 8
external-author trial surrogate. This project is intentionally close to
raw generator output so release reviewers can inspect what a new author
starts from.

## Build

```sh
tol --check-only src/main.tol
```

## Test

```sh
tol-tester tests token-positive
```

## Files

- `src/main.tol` - scaffold contract using `@stdlib/token`
- `tests/token-positive.tol` - smoke test for the generated pattern
- `replay/token-replay.json` - deterministic replay trace stub
- `deploy/deploy.json` - deployment skeleton
- `artifacts/*.json` - opcode, method-id, error-code, and replay observability maps

This project is retained as the under-one-hour author-trial scaffold.
