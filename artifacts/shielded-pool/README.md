# Shielded pool frozen inputs

`PROFILE.md` is the byte-frozen V1 implementation profile. Its content was
moved here unchanged from `doc/shielded-pool-v1-profile.md`: changing even an
internal path reference would change the profile hash used by genesis.
Consequently, path mentions *inside* that file describe its historical
location. The current generated manifest is `genesis-manifest.json`, whose
`profile.path` points here. `CEREMONY.md` is the ceremony procedure.
