# Upstream notice

This integration vendors and adapts smart-contract source code from the official TON Foundation repositories `ton-blockchain/bridge-func` (both the `master` and `bsc` network branches) and `ton-blockchain/bridge-solidity`, pinned in `UPSTREAM.lock.json`.

The FunC plane is distributed under GPL-3.0 and the Solidity plane under MIT. TOS preserves the upstream licenses and attribution. Historical network BOCs, prebuilt compile outputs, deployed addresses, oracle key sets, and mainnet deployment command files are intentionally excluded and must not be reused for TOS.
