# A03 first original-evidence batch: E16, F01, X01

`a03-first-batch.json` indexes **actual retained** source blobs, raw files, binary snapshots, independent reviews and CI metadata for three task IDs against memo task table `ae2be260e355277893453d4883407d2b1feb06b6`. `scripts/a03_first_batch.py` rehashes every indexed byte, re-reads the fixed memo task table and requires the snapshot to restate every row. Each entry is judged by its snapshot status, not by its ID: a signed row must index a real-chain run with a unique natural exit marker matching `reported_exit`, binary snapshots, a fixed review and the CI runs that row names; an open row may index only an offline candidate. The batch is not an A03 acceptance record: every row has `accepted=false`, a bounded applicability scope, explicit gaps and per-ID invalidating changes. The checker returns `integrity_passed=true` only for valid indexed bytes; its default development-gate exit remains 1. `--inventory-only` exits 0 for a valid index without changing that gate result.
