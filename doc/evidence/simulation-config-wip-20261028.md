## Author self-check

- Callers: searched declarations, definitions and CMake/CI targets. The current caller is the native test; production integration is pending in this same branch. Existing public proof entry points, request schemas and callers are unchanged.
- Proof order: bound the raw TL reply before copying it; check the answer's exact target; preflight both BOC headers and their combined cell budget before native cell allocation; bind the state root through the target's block header; extract the config subtree with no optional extraction flags; scan every reachable representation for missing/exotic content; only then extract Capabilities, PrevBlocks, WorkchainInfo and SpecialSmc. No server mode bit establishes completeness. Unrelated state proof branches remain allowed to be pruned.
- Completeness: load and classify a cell before hash deduplication, including virtualized representations. Pruned branches are Incomplete; nested Merkle proof/update cells are Unsupported. Ordinary and library-reference cells are complete representations; actual execution library resolution is still a separate future requirement. The scanner does not treat a missing subtree as an absent parameter. A complete dictionary can establish absence without requiring parameter48 to exist.
- Resources: provisional internal limits are16MiB reply,131072 combined proof BOC cells,65536 unique configuration cells and depth1023. Each reachable unique ordinary cell contributes at most four pending references. The visited set is checked before insertion and all references/set/buffers/config ownership are call-scoped. There are no caches, persistent handles, queues, background threads, descriptors, sockets or files. Refusal errors are fixed literal text and codes. These numbers are bounded implementation candidates, not accepted phone performance budgets or an ABI freeze.
- Arithmetic: proof-cell subtraction is checked by first bounding each operand; counts are bounded before allocation/traversal. No money arithmetic is added. Header parsing itself allocates no cell graph. Existing bounded TL decoding copies and native BOC allocation still require platform peak-resource measurement as part of the complete feature.

Wrong labels and foreign block proofs are tested separately, plus corruption, bytes, sharing, missing/virtualized cells, nested proofs, dictionary absence and exact cell/depth boundaries.
