# Slice 3 External Author Trial

This document records the Stage 8 repo-side surrogate. The actual
external-author trial is pending because it requires a human author who
did not implement the compiler.

## Repo-Side Surrogate

The surrogate examples are generated by the real `tol new` command:

| Example | Pattern | Source | Test |
| --- | --- | --- | --- |
| `examples/slice3/jetton-author-trial` | Jetton | `src/main.tol` | `tests/jetton-positive.tol` |
| `examples/slice3/nft-author-trial` | NFT | `src/main.tol` | `tests/nft-positive.tol` |

`scripts/check-slice-3-release-package.py` verifies both examples by
running `tol --check-only`, running their generated tol-tester smoke
tests, and validating manifest/replay/deploy/observability JSON.

## Under-One-Hour Path

| Step | Target time |
| --- | --- |
| Generate or open the Jetton/NFT scaffold | 5 minutes |
| Inspect `src/main.tol`, `manifest.json`, and opcode/error maps | 10 minutes |
| Fill project-specific owner/admin/content fields | 15 minutes |
| Run `tol --check-only src/main.tol` and `tol-tester tests` | 10 minutes |
| Inspect replay/deploy stubs and audit checklist | 15 minutes |
| Buffer for local fixes | 5 minutes |

Total target: 60 minutes.

The automated surrogate proves the command path and checked artifacts
exist in-repo. It does not replace the required human sign-off for the
release branch.
