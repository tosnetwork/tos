# Shared BR1 Bond codec

This crate contains the existing pure Bond cell codec and deterministic deployment
identity helpers. The node contracts module re-exports these same types; the BR1
client uses them directly without depending on the node's RPC, proof-process or
operator adapters. The fixed contract BOC remains in `crypto/smartcont` and is not
regenerated by this extraction.

The codec validates structural identity. A decoded StateInit or Bond config is
not evidence of current on-chain eligibility. Callers must independently verify
current Bond and pool state, release pins and the quote before submitting.

The implementation is moved from the contracts module. Equivalent direct Result
returns satisfy standalone Clippy; reserve subtraction remains checked with an
explicit zero floor. Frozen deployment/config/code/signing hashes were generated
from the pre-extraction implementation at `0ef7c2643`. Existing cell, policy and
signature-domain tests remain, with designated assertion controls in
`test/bonded-relayer/native_bond_codec_controls.py`.

Run from the repository root:

```sh
cargo test --locked --manifest-path tools/bonded-relayer/bond-codec/Cargo.toml
cargo clippy --locked --manifest-path tools/bonded-relayer/bond-codec/Cargo.toml --all-targets --no-deps -- -D warnings
python3 test/bonded-relayer/native_bond_codec_controls.py --out /tmp/br1-bond-controls --target-dir tools/bonded-relayer/bond-codec/target
```

Use a fresh output directory for controls. This crate does not implement wallet
custody, a durable payment journal, Tor lifecycle or mobile App integration.
