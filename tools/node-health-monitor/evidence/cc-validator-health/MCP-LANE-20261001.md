# MCP lane: real models judging through the six tools (2026-10-01)

Owner request: close the gap between "the MCP server exists" and "Codex or
Claude actually judges validator health through it". Scope: the orchestrator
`scripts/mcp-judge.py`, the adapter's evidence log and client negotiation,
the binding validator and its tests, the first real runs, a unit template.

## What was missing and what closed it

| Gap | Closure |
| --- | --- |
| No way to start a model session whose only tools are the broker's | `mcp-judge.py` issues grants (≤ 4 nodes each), writes one-use credentials, starts Claude (`-p --strict-mcp-config --restricted`) or `codex exec` (private home) with only the adapter servers |
| The adapter died on a real client's first frame (`server/discover`) and on a protocol version it did not know | unknown methods get JSON-RPC method-not-found, unknown notifications are dropped, `2025-11-25` is negotiated to `2025-06-18` in header and body; red-first test |
| Nothing recorded what the tools returned, so citations could not be bound | adapter evidence log (tool, request id, status, error code, argument names, evidence id/node/parents/hash), 0600, O_EXCL, 4 MiB bound; red-first test |
| No acceptance rule for a tool-using answer | contract, cited ids ⊆ tool-returned ids, each non-healthy node explained by its own evidence, failed sessions not accepted as "insufficient evidence"; unit tests for every rule |
| The AURA bridge refuses MCP servers | Codex lane uses `codex exec` with a private home; the push lane's home stays tool-free |

## Boundaries that stay

- A model client that truncates tool output (Codex did at ~16 KB) must
  re-query with a smaller component set; the instruction tells it to.
- A grant pins its watermark; a session longer than the resident window pauses
  the broker's import until the grant expires (200 s). Two lanes should not
  run at once; a second concurrent session was refused a grant (503) while the
  first held one.
- Cost: one Claude run was about 0.30 USD; the installed timer runs the Codex
  instance every thirty minutes, the Claude instance is provided but not
  enabled.
- The lane proves the model can read and cite; it does not prove root-cause
  analysis, and it never changes a verdict.
