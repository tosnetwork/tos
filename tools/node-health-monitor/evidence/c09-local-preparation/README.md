# C09 real local preparation

This is preparation evidence, not C09 acceptance. The owner authorized real
local development nodes. Four PQ validators, two non-validator observers and
the DHT were initialized without deleting unrelated resource measurements.

The initial 60-second calibration ended with exit 1: the seven node cgroups
had no `io.stat` because I/O accounting was disabled. Runtime I/O accounting
was enabled on those seven units. A fresh calibration completed with zero
instrument errors and three observations of advancing, agreeing complete
masterchain IDs. The original red remains retained. These two calibrations
precede the sampler's formatting commit; they do not claim execution of an
exact committed source snapshot.

Six real edge/probe lanes and private-CA mutual TLS ingress were started.
Each edge reads its fixed validator PID's process/cgroup data as the same
service UID. Each edge is the sole scheduled native collector. Manager
reachability rules use actual probe observations; they do not infer consensus
correctness. No external alert receiver or model service is enabled yet.

The C04 native paths are identical between the independently reviewed native
candidate `e89ca322253e1c7a7acb87d16d63f974e462158e` and the accepted development
baseline `35ba59c111dd74518e6e661bcd1984598d493907`. A bounded two-job build
completed; its pinned binary was installed under a separate name. Runtime
service overrides select its native v2 measurement profile. This is a test
profile, not a passed performance gate or a default production deployment.

## Actual integration refusal

All six full edge snapshots returned HTTP 503 even though their heartbeats
reported usable process, native and cgroup caches. The native publisher uses
a 32-hex process epoch; `/proc` uses a boot identity, PID and start ticks. The
consumer requires those distinct namespaces to be equal. Exact consumer
source hashes, six heartbeat responses and six refused snapshots are retained
outside the repository and indexed here. The source explanation is labelled
an inference; the handler's HTTP refusal is an actual observation. The
consumer owner is correcting the binding while preserving both identities.

The first local CA omitted its signing key-usage extension. A strict client
refused it; the certificate was corrected and TLS clients restarted without
disabling certificate checks. The original public certificate is retained.
